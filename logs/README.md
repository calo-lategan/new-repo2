# Session logs

Auto-collected session logs from the JetArm v5 sorting node. Generated by
`tools/push_logs.sh` on the device.

Each file is one session of `custom_sortingv5` or `tune_uiv5`. Files are
text-only — no camera frames or binary artifacts.

Files in this folder are pushed to GitHub by the operator (or the
"Push logs to repo" button in the tuner UI) so subsequent Claude Code
sessions can read them for debugging context.
